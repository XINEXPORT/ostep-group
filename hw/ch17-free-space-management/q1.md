# Question 1

First run with the flags **-n 10 -H 0 -p BEST -s 0** to generate a few random allocations and frees.
- Can you predict what alloc()/free() will return?
- Can you guess the state of the free list after each request?
- What do you notice about the free list over time?

# Answer
- The list only grows and never shrinks.
- With coalescing turned off, every free() adds a new entry and nothing ever merges entries back together.
- This creates tiny unusable slivers of free space in the list.
- Best fit is choosing to split at the front of the list causing uneven distribution of free space.

**Run the following:** python3 malloc.py -n 10 -H 0 -p BEST -s 0 -c

```
seed 0
size 100
baseAddr 1000
headerSize 0
alignment -1
policy BEST
listOrder ADDRSORT
coalesce False
numOps 10
range 10
percentAlloc 50
allocList
compute True
```
