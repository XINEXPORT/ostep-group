# Chapter 17: Free-Space Management

The meaning of the ```malloc.py``` flags
- ```-n 10``` → generate 10 operations (allocs/frees)
- ```-s 0``` → random seed 0
- ```-p BEST``` → use the best-fit policy from the chapter (search the whole list, pick the smallest chunk that's still big enough)
- ```-H 0``` → no header overhead per allocation
- ```-c``` → "compute answers" - show the alloc/free return and what the free list looks like# Chapter 17: Free-Space Management
